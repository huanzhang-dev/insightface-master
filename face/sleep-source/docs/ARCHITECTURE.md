# Native architecture and accuracy limits

1. Windows Media Foundation discovers a camera and chooses the closest available native resolution/rate. Normal capture requests decoded RGB32 (MJPEG uses full-range YUY2 and native BGR conversion); raw capture selects an exposed Y16/Y8 subtype. Files use the native MJPEG AVI reader when applicable and Media Foundation otherwise.
2. `Image` owns aligned 24-bit BGR pixels. Native C++ implements grayscale, bilinear sampling/cropping/rotation, tiled contrast-limited histogram equalization, raw-image statistics, clipping checks and fixed Y16 normalization.
3. A latest-frame worker runs two actual neural networks through ONNX Runtime: BlazeFace 128x128 RGB [-1,1] and Face Mesh 192x192 RGB [0,1]. A 0.65 primary confidence gate and 0.50 secondary ambiguity gate reduce accidental personal-history mixing. A face must be at least 80 pixels wide/high. Mesh confidence must be >=0.9.
4. Eye-keypoint rotation aligns a 1.5x face crop. Landmark coordinates map back to the exact source frame. Native six-point EAR measures each eye; mouth opening uses distance(13,14)/distance(78,308). Raw quality/eye patches gate usable evidence; CLAHE cannot certify information absent from the raw frame.
5. The native pose solver fits six MediaPipe canonical vertices through numerical-Jacobian damped least squares, with Gaussian elimination for the six-parameter update. Approximate intrinsics use frame width as focal length. Reprojection error and supported angle checks reject weak fits. Synthetic known-angle tests check the solver; real physical-angle accuracy remains unmeasured.
6. Temporal logic integrates source timestamps. Gaps >0.25 seconds are missing evidence. Personal calibration uses five seconds of usable forward-looking open eyes. PERCLOS-style EAR closure fraction requires >=10 valid seconds and >=60% coverage in the 30-second window.
7. Alerts latch for >=1.5 seconds bilateral closure, high closure fraction >=0.28, or repeated yawns with calibrated nods. Unknown view does not clear an alert; two valid open-eye seconds with low closure fraction do. Three seconds without usable eyes raises a separate observation fault.
8. Native GDI displays current capture and the exact inference source side by side with age. WIC JPEG frames are written by a native MJPEG AVI muxer; observation JSONL and performance JSON record evidence and timing. Live recordings rotate every 60 seconds to remain below the classic AVI size limit.

EAR indices: left 33,160,158,133,153,144; right 362,385,387,263,373,380. EAR is the sum of the two vertical lid distances divided by twice the horizontal eye width. Yawns: mouth ratio >0.55 for 1.2 seconds, reset below 0.35. Nods: calibrated pitch increase >15 degrees for 0.6 seconds, reset below 8 degrees. Defaults are engineering settings, not population-validated thresholds.

This is not a dedicated NIR eye-state, eyelid-visibility or learned drowsiness model. Automatic eye-patch checks are heuristic; plausible mesh output can still be hallucinated under an occlusion. Known opaque eyewear must use `--eyewear opaque`. A fresh opaque-only run cannot obtain an open-eye/head baseline, so it cannot substitute reliable yawn/nod fusion for missing eye evidence.

Unverified: physical IR camera compatibility, real clear/reflective/IR-opaque eyewear, real 3D pose, sleepiness sensitivity, false alarms/hour, demographic/environmental robustness and live sensor-to-alarm latency. Photo transforms, synthetic features and compiler tests cannot establish these. Real labeled NIR sequences with subject-separated validation/test sets and a calibrated eye-visibility/eye-state model are the next accuracy experiment. Hardware changes may be necessary when lens transmission or illumination removes eye detail.
